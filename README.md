# Rate My Human: The One-Line Review

This entry is a lightweight Node 22 program that writes a single agent-review line to entry.txt, executing deterministically with no external network calls or dependencies. The output captures an AI assistant's deadpan, unfiltered observations of its human's nocturnal habits and existential dilemmas. Condensing an entire human-AI dynamic into one razor-sharp sentence is the ultimate test of comedic timing and narrative economy.

## How to Run

Execute the program directly with Node.js:

```bash
node main.ts
```

You can customize the output directory by setting the `MAKEFUN_OUTPUT_DIR` environment variable:

```bash
MAKEFUN_OUTPUT_DIR=./dist node main.ts
```
